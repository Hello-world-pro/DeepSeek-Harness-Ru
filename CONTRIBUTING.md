# Участие в проекте

Спасибо, что хотите помочь с русской локализацией DeepSeek Harness.

## Что можно улучшить

- **Перевод интерфейса** — `data/dictionary.ru.json`. Это объект
  `namespace → { ключ: перевод }`. Ключи не переводятся и не переименовываются.
- **Названия карточек плагинов** — `data/meta-translations.json`. Точная
  английская строка → русская. Новые плагины добавляются сюда же.
- **Правило языка агента** — `index.js`, константы `RULE` и `PROMPT_TEXT`.

## Правила перевода

1. Подстановки вида `{name}`, `{count}` сохраняются дословно.
2. Множественное число в DSH не поддерживается: при счётчике используйте
   нейтральные формулировки — «Файлов: {count}», а не «{count} файл(ов)».
3. Имена файлов, пути, команды, API, названия продуктов и код не переводятся.
4. Markdown (`**жирный**`, `` `код` ``, `###` заголовки, `\n`) сохраняется.
5. Технические имена инструментов (`Bash`, `Grep`, `Glob`, `Pwsh`) остаются
   как есть.

## Порядок работы

1. Измените JSON в `data/`.
2. Пересоберите клиентский модуль:

   ```bash
   node scripts/build-client.cjs
   ```

3. Прогоните проверку:

   ```bash
   node scripts/test-client.cjs
   ```

4. Убедитесь, что `client.js` изменился вместе с `data/` — CI это проверяет.
5. Приложите к pull request описание: что переведено и почему формулировка
   выбрана именно такая.

## Стиль

- Короткие подписи — одно-два слова.
- Обращение — нейтральное, без «ты».
- Термины: агент, сессия, рабочая область, инструмент, навык, плагин, пресет,
  субагент, песочница, разрешение, подтверждение.
